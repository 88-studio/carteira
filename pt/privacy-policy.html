Política de Privacidade

Última atualização: 25 de abril de 2026

Carteira - Planejador de Orçamento ("o Aplicativo") é desenvolvido por Henrique Horbovyi. Esta Política de Privacidade explica como o Aplicativo coleta, utiliza e protege suas informações.

1. Informações que Coletamos

1.1 Dados Fornecidos por Você

Ao utilizar o Aplicativo, você pode inserir as seguintes informações, que são armazenadas localmente apenas no seu dispositivo:

  • Orçamentos e alocações de orçamento
  • Detalhes de despesas (valor, descrição, categoria, data, recorrência)
  • Baldes (nome, alocação, cor, categoria)
  • Metas financeiras e registros de metas
  • Despesas fixas
  • Categorias personalizadas
  • Dados do formulário de feedback (nome, email, mensagem)

1.2 Dados de Notificações (Rastreador de Despesas)

Se você ativar o recurso opcional de Rastreador de Despesas, o Aplicativo utiliza o Serviço de Leitura de Notificações do Android para ler notificações de aplicativos bancários e financeiros que você selecionar. Os seguintes dados são lidos:

  • Título e conteúdo de texto da notificação
  • Texto estendido da notificação
  • O nome do pacote do aplicativo de origem

Esses dados são processados no seu dispositivo para detectar valores de despesas e nunca são transmitidos para nenhum servidor. Você controla quais aplicativos são monitorados e pode desativar este recurso a qualquer momento.

1.3 Dados Coletados Automaticamente

O Aplicativo utiliza serviços de terceiros que podem coletar certas informações automaticamente:

Serviço Dados Coletados Finalidade
Firebase Analytics Eventos de uso anônimos, tipo de dispositivo, versão do SO, versão do aplicativo Entender como o Aplicativo é usado e melhorar a experiência
Firebase Crashlytics Logs de falhas, stack traces, modelo do dispositivo, versão do SO Identificar e corrigir bugs e falhas
Google AdMob ID de publicidade, informações do dispositivo, endereço IP, dados de interação com anúncios Exibir anúncios para apoiar os recursos gratuitos do aplicativo

1.4 Eventos de Análise

O Aplicativo rastreia os seguintes eventos anônimos por meio do Firebase Analytics:

  • Primeira abertura do aplicativo
  • Conclusão do onboarding
  • Permissão de notificação concedida ou negada
  • Despesa adicionada manualmente
  • Despesa adicionada via notificação
  • Balde criado

Esses eventos não contêm dados financeiros pessoais, como valores, descrições ou informações de conta.

2. Como Usamos Suas Informações

  • Dados locais: Usados exclusivamente dentro do Aplicativo para fornecer recursos de planejamento de orçamento, rastreamento de despesas e metas financeiras.
  • Dados de análise: Usados para entender padrões de uso e melhorar o Aplicativo.
  • Dados de falhas: Usados para identificar e resolver problemas técnicos.

3. Armazenamento e Segurança dos Dados

  • Todos os dados financeiros pessoais (despesas, orçamentos, metas, categorias) são armazenados localmente no seu dispositivo usando um banco de dados local criptografado e preferências seguras.
  • Nenhum dado financeiro é transmitido para servidores externos.
  • Dados de análise e falhas são transmitidos para os serviços Firebase do Google usando conexões criptografadas.

4. Publicidade

O Aplicativo utiliza o Google AdMob para exibir anúncios. O AdMob pode coletar e usar identificadores de dispositivo (como o ID de publicidade), endereço IP e dados gerais de uso para veicular e personalizar anúncios, de acordo com a política de privacidade de publicidade do Google.

Importante: Dados financeiros lidos de notificações por meio do recurso Rastreador de Despesas — incluindo valores de transações, nomes de comerciantes e qualquer outro conteúdo de notificação — nunca são compartilhados com o Google AdMob ou qualquer outro provedor de anúncios. Esses dados são processados inteiramente no seu dispositivo e não são usados para segmentação ou personalização de anúncios de forma alguma.

Você pode desativar a publicidade personalizada a qualquer momento nas configurações do seu dispositivo (Configurações > Google > Anúncios > Desativar personalização de anúncios).

5. Compartilhamento de Dados

Nós não vendemos, negociamos ou compartilhamos seus dados financeiros pessoais com terceiros. Os dados compartilhados externamente são limitados a:

  • Análises anônimas e relatórios de falhas enviados ao Firebase.
  • Identificadores de dispositivo e dados de interação com anúncios compartilhados com o Google AdMob para veiculação de publicidade. Nenhum dado financeiro, conteúdo de notificação ou informação de despesas é compartilhado com provedores de anúncios.

6. Permissões

O Aplicativo solicita as seguintes permissões:

Permissão Motivo
Internet Necessária para Firebase Analytics, Crashlytics e veiculação de anúncios via Google AdMob
Enviar Notificações Para enviar lembretes e alertas locais
Leitura de Notificações Opcional: para ler notificações bancárias para rastreamento automático de despesas

7. Privacidade de Crianças

O Aplicativo não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente informações pessoais de crianças. Se você acredita que uma criança nos forneceu dados, entre em contato conosco para que possamos tomar as medidas adequadas.

8. Seus Direitos

Como seus dados financeiros são armazenados localmente no seu dispositivo, você tem controle total sobre eles:

  • Excluir todos os dados: Limpe os dados do Aplicativo nas configurações do seu dispositivo ou desinstale o Aplicativo.
  • Desativar o Rastreador de Despesas: Revogue o acesso a notificações a qualquer momento nas configurações do Aplicativo ou nas configurações do sistema do seu dispositivo.
  • Desativar análises: Você pode limitar o rastreamento de anúncios e análises nas configurações do seu dispositivo.

9. Links e Serviços de Terceiros

O Aplicativo pode conter links para serviços de terceiros (por exemplo, loja de aplicativos para avaliações). Não somos responsáveis pelas práticas de privacidade desses serviços externos. Recomendamos que você revise suas políticas de privacidade.

10. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. As alterações serão publicadas nesta página com uma data de revisão atualizada. O uso continuado do Aplicativo após as alterações constitui aceitação da política atualizada.
